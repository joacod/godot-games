# Godot Games

Small finished games built with [Godot Engine](https://godotengine.org/) for
learning and experimentation. Each game is a separate Godot project.

## Games

- [2D Platform](2d-platform/README.md): a ruined-fortress platformer with
  forgiving jumps, three attacks, optional gems, and a final guardian.
  Includes a title screen, pause, level and arena retries, and a demo ending.
- [Beat 'Em Up](beat-em-up/README.md): a one-level street brawler with depth
  movement, a three-hit combo, two encounters, a boss, and a breakable
  health pickup. Includes menus, pause, audio settings, and a full-route retry.
- [The Closed Gate](point-and-click/README.md): a one-room point-and-click
  adventure. Look, use, and talk with five props, carry items, and finish one
  recoverable puzzle that opens the gate. Includes pause and restart.
- [Last Light Clearing](survivors/README.md): a top-down survival run. Move
  the Keeper while automatic weapons clear enemies, collect XP, choose
  upgrades, and survive three minutes. Includes pause and a fresh retry.

`shooter/` holds design notes and is not a playable project.

## Play and develop

Use Godot 4.7; development checks use 4.7.2. Import a game's `project.godot`
in the Godot Project Manager, open it, and press **F5** to play.
Each game's README covers controls, editing locations, and validation.

## Publishing destinations
