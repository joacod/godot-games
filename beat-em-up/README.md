# Beat 'Em Up

A planned single-player, one-level street brawler inspired by Final Fight.
Build a complete, enjoyable game first; make later art swaps straightforward
through ordinary Godot scenes and Inspector values.

**Status: planning only.** No Godot project, gameplay, or downloaded assets exist
in this folder yet. Implementation starts only when a step is requested.

## Start here

- [Implementation plan](docs/PLAN.md): scope, order, status, and step boundaries.
- [Game design](docs/DESIGN.md): controls, combat rules, level, and scene ownership.
- [Asset brief](ASSETS.md): CraftPix candidates, required animations, and replacement rules.
- [Acceptance checklist](docs/ACCEPTANCE.md): automated and hands-on validation.

Planned stack: Godot 4.7, checked with 4.7.2, GDScript, Compatibility renderer.
This is an independent project; it does not depend on `2d-platform`.

To begin later, request **“Implement Step 01 in beat-em-up.”** Each step requires
a short approach review before non-trivial implementation, ends with validation,
and stops before the next step. Creating this plan does not authorize implementation.
